# Railway deployment

Create a Railway project, add PostgreSQL, then add the repository as the web service. Reference the database service's `DATABASE_URL`. The application listens through Next's Railway-compatible `PORT` handling.

Required production variables: `DATABASE_URL`, `BETTER_AUTH_SECRET`, `BETTER_AUTH_URL`, `BETTER_AUTH_TRUSTED_ORIGINS`, `AUTH_EMAIL_FROM`, `RESEND_API_KEY`, `FOFL_LEAGUE_SLUG`, and `LEAGUE_TIMEZONE=America/Chicago`. Public registration is not supported. Configure `MFL_BASE_URL`, `MFL_LEAGUE_ID`, and `MFL_SEASON` for imports. MFL username/password are optional and server-only. Add `CRON_SECRET` before scheduled imports.

`railway.json` is the deployment authority: Railpack runs `pnpm build`, Railway runs `pnpm db:migrate` in its pre-deploy container, and the service starts with `pnpm start`. A failed migration prevents the new deployment from proceeding. Railway probes `/api/health` for process liveness during rollout; `/api/ready` is the stricter release-readiness signal. Readiness requires valid production configuration, the Authentication / Owners / Franchises migration set, the configured league, and either the configured MFL season or at least one league season. It returns only variable names and reason codes—never secret values—and must not be substituted for liveness during a rolling migration.

Production responses send a static Content Security Policy, clickjacking protection, a restrictive browser permissions policy, and two-year HSTS. The policy intentionally permits Next.js inline bootstrap scripts; moving to nonces would make every page dynamic and should be evaluated as an explicit caching and rendering tradeoff. Verify the headers at the public HTTPS edge because a proxy can override application headers.

Before opening production access, run `pnpm db:sync-mfl` to provision the FOFL league, season, and franchises. Set `AUTH_BOOTSTRAP_COMMISSIONER_EMAIL` to the first commissioner's exact address, create the account at `/bootstrap-commissioner`, verify it by email, confirm its audited commissioner membership, and immediately remove the variable (the route then becomes a 404). That commissioner can use `/commissioner/owners` for all subsequent owner invitations and franchise access. Confirm a real verification email, password-reset email, invitation acceptance, session revocation, and a database restore in staging before launch.

Every pull request and main-branch push runs lint, type checking, the full unit/integration suite, a production build, and Chromium E2E through `.github/workflows/ci.yml`. Create a protected GitHub `staging` environment with a non-secret `STAGING_BASE_URL` environment variable. After provisioning and closing bootstrap, dispatch **Staging release smoke**. It runs `pnpm smoke:staging` and requires HTTPS, liveness, full database/configuration readiness, the production security-header baseline, disabled development authentication, no framework disclosure header, and a 404 from the bootstrap route. A passing smoke run is necessary but does not replace the real email and restore exercises above.

Run `pnpm db:cleanup-auth` daily as a Railway cron command. It transactionally deletes expired sessions and verification tokens plus rate-limit keys idle for more than 24 hours, reports counts only, and retains all active credentials. Apply the release migration first so its expiration indexes are present.

Configure daily, weekly, and monthly PostgreSQL volume backups plus point-in-time recovery before launch. Complete the read-only sibling-service restore drill in [database disaster recovery](disaster-recovery.md) before production and quarterly thereafter. `pnpm db:verify-restore` refuses the configured live database and validates the restored league's commissioner access, membership/primary-owner invariants, and stable MFL identities before any cutover.

The future worker service should share domain/database modules and claim durable `scheduled_jobs`. Redis is not required today; introduce it behind a queue interface when retryable imports, scoring fan-out, or notifications justify it.
